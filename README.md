# Littera

**Taller literario total.** Nueve mundos, un solo flujo.

Creado por **Jose Luis Gaete Hernandez** (ps.josegaetehernandez@gmail.com).

## Que es

Un ecosistema completo para escribir, estudiar, analizar, imprimir y publicar literatura.
Todo funciona en el navegador, sin servidor, sin cuentas, sin distracciones.

## Los nueve mundos

1. **Escritorio** - Home con accesos rapidos.
2. **Scriptorium** - Cuaderno infinito de captura.
3. **Taller** - Once modos: prosa, cuento, novela, historia ilustrada, verso, poesia visual, diario, cronica, aforismos, fanzine, revista.
4. **Biblioteca** - Mente maestra. 165+ fichas de retorica, linguistica, semiotica, filosofia del lenguaje, ontologia, narratologia, teoria literaria y critica. Flashcards, ejercicios, repeticion espaciada, ruta por niveles, modo examen.
5. **Laboratorio** - Analisis textual, estilometria, riqueza lexica, legibilidad, clima emocional, comparador de obras.
6. **Imprenta** - 12 formatos de papel, portadas personalizadas, imposicion de fanzine, exportacion a PDF.
7. **Archivo** - Gestion de obras.
8. **Plaza** - Envios, contactos, calendario de convocatorias.
9. **Ritual** - Temporizador de escritura.

## Modulos complementarios

- **Personajes** - Fichas vinculadas a novelas.
- **Timeline** - Cronologia interna vs orden narrativo.
- **IA** - Asistente literario con multiples proveedores.

## Como usarlo

1. Abre `index.html` en tu navegador (o usa el acceso directo).
2. Todo se guarda en `localStorage`.
3. Exporta/importa respaldos JSON desde el topbar.

## Stack

- HTML5 + CSS3 + JavaScript vanilla (sin frameworks)
- Google Fonts (EB Garamond, Instrument Serif, Inter, Literata, JetBrains Mono)
- localStorage para persistencia
- IA opcional (OpenAI, Anthropic, Groq)
